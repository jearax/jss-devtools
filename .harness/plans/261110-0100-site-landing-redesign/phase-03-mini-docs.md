# Phase 3: Mini docs

## Steps

1. Same header and page frame as the landing.
2. Sidebar: mono uppercase group labels, one selected-item pattern (selected token and a marker), hover
   distinct from selected, one indent rhythm; on mobile the sections open in a drawer (follow the design
   system site's `SectionsDrawer`).
3. Reading column: `max-w` reading measure, heading rhythm from text roles, inline code chip, tables
   with a header surface; code blocks as terminal surfaces in both themes with copy.
4. Table of contents with an active marker that follows the scroll position.
5. Previous and next as two bordered links with the page title and direction label.
6. Keep page content; add or rename a heading only where the structure needs it. Keep the docs short.
