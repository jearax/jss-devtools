# 0011 AgentKit for agent setup, for now

## Context

The repository needs to tell agents what is true. AgentKit is already installed globally
(`ak` 3.0.0-beta.25), and `ak init --dry-run` on 2026-10-19 reported that a project init tracks
zero files: kits install globally, so the project-level init only registers the project under
`.agentkit/`.

## Decision

Use AgentKit for now. Keep docs in the global CLAUDE.md layout under `docs/`.

## In the user's words

> "Chính nó dùng tạm `ak`" (user, 2026-10-19)

## Consequences

- `.agentkit/` is not committed. It is regenerated by `ak` commands and embeds absolute local paths,
  so it is machine state rather than shared truth.
- "For now" is doing real work in this decision. The CLI will eventually generate its own harness for
  consumer repositories, and that is the point at which this becomes a dogfooding question rather
  than a tooling choice.
